# Nested Loop Practice Questions (JavaScript)

Practice these questions from beginner to advanced. Try solving each one
yourself before checking any solution.

## Level 1: Beginner

### Q1. Print a square pattern

For `n = 5`:

``` text
* * * * *
* * * * *
* * * * *
* * * * *
* * * * *
```

## Practice Tips

-   The outer loop usually controls the rows.
-   The inner loop usually controls what gets printed in each row.
-   Before coding, write down how many times the inner loop should run
    for each row.
-   Use `process.stdout.write()` to print on the same line.
-   Use `console.log()` after the inner loop to move to the next line.
-   Start with the beginner questions and move up gradually.
